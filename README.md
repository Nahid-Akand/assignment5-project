# DevStack

DevStack is a simple web app for exploring different development technologies and building a stack for your projects.

The idea behind the project is to make it easier to discover useful technologies in one place. You can browse technologies, check their category, difficulty, rating, and description, and add the ones you like to your own stack.

## Technologies Used

- React
- TypeScript
- Vite
- Tailwind CSS
- DaisyUI
- React Toastify
- JSON

## Features

### Technology Explorer
Browse different frontend, backend, database, language, styling, DevOps, and development tools. Each technology includes useful information such as its description, category, difficulty, and rating.

### Build Your Stack
Add technologies to your own stack while exploring. You can remove individual items or clear the entire stack whenever you want.

### Responsive Design
The website is designed to work across desktop, tablet, and mobile screens. The navigation, technology cards, stack section, and footer all adapt to different screen sizes.

## Why I Built This

I built DevStack as a way to practice building a complete React application while working with reusable components, JSON data, responsive layouts, and state management.

It also gave me a chance to create a clean interface where developers can quickly explore technologies and organize the tools they want to use.

## Project Structure

The project is built with reusable React components, with the technology information stored separately in a JSON file. This keeps the UI components clean and makes the technology list easy to update.
